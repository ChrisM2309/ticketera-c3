# Activación manual del sitio

Completar esta lista solo cuando se decida publicar e indexar el sitio. Esta fase no activa la indexación.

- [ ] Confirmar que el dominio HTTPS sirve el deploy final de Vercel y que `NEXT_PUBLIC_SITE_URL` coincide exactamente con ese dominio.
- [ ] Revisar `https://<dominio>/robots.txt` y `https://<dominio>/sitemap.xml`; confirmar que el rastreo y las URLs públicas previstas son correctos.
- [ ] Confirmar que las migraciones y los ajustes operativos necesarios ya están aplicados.
- [ ] En `/admin/ajustes/`, activar indexación y aceptar la confirmación DEMO.
- [ ] En Google Search Console, registrar `https://<dominio>/sitemap.xml` y anotar la fecha.

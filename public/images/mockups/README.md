# Fotos temporales (mockups)

Fotos de stock para portadas de eventos DEMO. No son fotos de los eventos ficticios y no deben presentarse como tales.

Se muestran solo cuando un evento no tiene `image_path` propio. Cada línea de C3 tiene su foto (ver `src/features/catalog/images.ts`).

| Archivo | Línea | Fuente | Licencia |
|---|---|---|---|
| `compite.jpg` | Compite | [Two men sitting in front of a laptop computer](https://unsplash.com/photos/two-men-sitting-in-front-of-a-laptop-computer-Hp4RPL_Z6wE), Unsplash | Unsplash License (uso libre, sin atribución obligatoria) |
| `crea.jpg` | Crea | [Three men sitting while using laptops and watching man beside whiteboard](https://unsplash.com/photos/three-men-sitting-while-using-laptops-and-watching-man-beside-whiteboard-wD1LRb9OeEo), Unsplash | Unsplash License |
| `conecta.jpg` | Conecta | [Audience in a conference](https://unsplash.com/photos/audience-in-a-conference-EVgsAbL51Rk), Unsplash | Unsplash License |

Las fotos de `public/images/temp/` no se usan aquí porque muestran personas identificables y patrocinadores de un evento real.

Para reemplazarlas, cambia el archivo con el mismo nombre o ajusta `coverImagePath`.

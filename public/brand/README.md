# Logotipos C3

Archivos oficiales del logotipo de C3, tomados del design system «C3». Úsalos tal cual: no los rotes, deformes, recoloreés ni les apliques degradados o texturas.

| Archivo | Cuándo usarlo |
|---|---|
| `logo-principal-color.png` | Logotipo a color sobre fondo claro |
| `logo-principal-blanco.png` | Logotipo blanco sobre fondo navy (cabecera y pie) |
| `isotipo-color.png` | Símbolo a color sobre fondo claro (avatares, iconos pequeños) |
| `isotipo-fondo-oscuro.png` | Símbolo blanco sobre fondo navy (iconos sobre fondos oscuros) |

Para el detalle de tamaños, áreas de protección y usos incorrectos, consulta «Uso del logotipo» en el design system C3.
